## 📝 Overview

**Supermarket** is a modern web application framework that simplifies the development of e-commerce platforms, combining a powerful backend with a sleek frontend for an exceptional user experience.

### Why Supermarket?

This project aims to streamline the creation of shopping applications while ensuring maintainability and scalability. The core features include:

- 🎨 **Consistent Design**: Utilizes Tailwind CSS for a cohesive look and feel across the application.
- ⚙️ **Robust Backend**: Built with Express and MongoDB, providing a scalable and maintainable server-side architecture.
- 🔒 **User Authentication**: Implements secure sessions and JWT for enhanced security and user experience.
- 🔄 **Modular Components**: Offers reusable UI components that promote code maintainability and speed up development.
- 🛒 **Seamless State Management**: Integrates user context and shopping cart state for a smooth user experience.
- 🌙 **Responsive Design**: Supports dark mode and responsive layouts, catering to diverse user preferences.

## 🚀 Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language**: TypeScript
- **Package Manager**: Npm
- **Container Runtime**: Docker

### Installation

Build supermarket from the source and install dependencies:

```sh
# Clone the repository
git clone https://github.com/D-e-D-a/supermarket

# Navigate to the project directory
cd supermarket
npm install
npm run dev
